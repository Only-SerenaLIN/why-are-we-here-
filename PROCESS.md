# Process

I used ChatGPT during the writing process for brainstorming, structuring my ideas, and improving the clarity of some English sentences.

The main idea of the essay is still based on my own experience as an art and design student learning programming. I first wrote down my own thoughts, especially my feeling that programming is not only about writing code, but also about understanding how digital systems shape creative decisions. I then used ChatGPT to help me organise these ideas into a clearer structure.

One suggestion from ChatGPT that I kept was the distinction between "describing" and "specifying". I found this useful because it matched my own experience: it is easy to tell an AI that I want something to feel "unsettling" or "interactive", but it is much harder to define exactly how the interaction should behave. This helped me explain why understanding programming still matters to me.

I also rejected some suggestions from ChatGPT. For example, it suggested using the common argument that "AI cannot replace human creativity because humans have emotions". I did not use this because I think it is too general and does not really answer my question. I am more interested in understanding how designers can keep control over creative decisions when AI can already generate code.

I also edited the final wording myself so that the essay reflects my own opinions and experience rather than sounding like a general argument about AI and technology.
